# Would like: querer com educação | gramatica
porque: No Módulo 9 aparece {{Would you like to have lunch here?|Você gostaria de almoçar aqui?}} e {{She would like to have dinner at the mall.|Ela gostaria de jantar no shopping.}} É o jeito educado de querer. Você vai usar muito no Módulo 16, para pedir comida: {{I'd like a coke, please.|Eu gostaria de uma Coca-Cola, por favor.}}
historia: Léo entra num restaurante chique e grita para o garçom: {{I want a soda!|Eu quero um refrigerante!}}
  O garçom levanta uma sobrancelha. Mia sussurra: 'Aqui a gente fala de **cartola**: {{I would like a soda, please.|Eu gostaria de um refrigerante, por favor.}}'
  **Want** é querer. **Would like** é querer **com educação**, o 'gostaria' do inglês.
dica: Para aceitar uma oferta, diga {{Yes, please.|Sim, por favor.}} Para recusar com educação, {{No, thank you.|Não, obrigado.}} Nunca {{Yes, I want.|Sim, eu quero.}} (soa seco).

=regra Would like: o 'gostaria' do inglês
gancho: Imagine dois jeitos de pedir um café: de moletom ({{I want coffee!|Eu quero café!}}) e de terno ({{I would like a coffee, please.|Eu gostaria de um café, por favor.}}). **Would like** é o terno.
resumo: Would like = gostaria de. É querer com educação, para todas as pessoas.
formula: sujeito + would like + a coisa
  sujeito + would like + to + verbo
porque: {{I would like a coke.|Eu gostaria de uma Coca-Cola.}}
  {{She would like to have dinner.|Ela gostaria de jantar.}}
  O **would** nunca muda: sem -s, sem do. Diga {{she would like|ela gostaria}}, nunca "would likes".
  Depois de would like, ou vem uma coisa (a coke) ou **to + verbo** (to have dinner).
compare: Em português dizemos 'eu gostaria de' em vez de 'eu quero' para ser educado.
  Em inglês é igual: **would like** no lugar de want.
ex: I would like a coke, please. | Eu gostaria de uma coca, por favor.
ex: She would like to have dinner at the mall. | Ela gostaria de jantar no shopping.
ex: We would like a table for two. | Nós gostaríamos de uma mesa para dois.
erro: She would likes a coke. | She would like a coke. | Ela gostaria de uma Coca-Cola. | O **would** nunca muda, e o **like** também fica puro: sem -s.
erro: I would to like a coke. | I would like a coke. | Eu gostaria de uma Coca-Cola. | Depois de **would** vem o **like**. O **to** só entra depois: would like **to** + verbo.
erro: I would like eat. | I would like to eat. | Eu gostaria de comer. | Com verbo, precisa do **to**: would like **to** eat.
quiz: Eu gostaria de uma coca: I ___ like a coke. | would | would; will; do
quiz: Ela gostaria de jantar: She would ___ to have dinner. | like | like; likes; liking

=pegadinha Would you like...? Oferecer e recusar
gancho: O would é um **ajudante** como o do. Por isso a pergunta e a negativa saem sozinhas, sem do e sem does.
resumo: Pergunta: Would vai para o começo. Negativa: would not (wouldn't).
formula: Would + sujeito + like + ... ?
  sujeito + wouldn't like + ...
porque: {{Would you like some water?|Você gostaria de um pouco de água?}}
  É o jeito mais educado de **oferecer** algo.
  Negativa: {{I would not like to close the office at night.|Eu não gostaria de fechar o escritório à noite.}} A forma curta é **wouldn't**.
  Nada de do ou does: o would já é o ajudante.
ex: Would you like to have lunch here? | Você gostaria de almoçar aqui?
ex: What would you like to drink? | O que você gostaria de beber?
ex: I would not like to close the office at night. | Eu não gostaria de fechar o escritório à noite.
erro: Do you would like some water? | Would you like some water? | Você gostaria de um pouco de água? | O would já é o ajudante: ele mesmo vai para a frente, sem **do**.
erro: Would you to like some water? | Would you like some water? | Você gostaria de um pouco de água? | Não entra **to** entre **you** e **like**.
erro: I don't would like to go. | I wouldn't like to go. | Eu não gostaria de ir. | A negativa do would é **would not** ou **wouldn't**, sem don't.
quiz: Você gostaria de água?: ___ you like some water? | Would | Would; Do; Are
quiz: Eu não gostaria: I ___ like it. | wouldn't | wouldn't; don't; won't

=dica I'd like: a forma curta de pedir
gancho: No restaurante ninguém fala {{I would like|eu gostaria}} inteirinho: encurtam para **I'd like**. É a frase número 1 de quem pede comida.
resumo: I'd like = I would like. Na fala e no pedido de comida, a forma curta é a mais usada.
porque: **I would** → **I'd**. **she would** → **she'd**. **we would** → **we'd**.
  O apóstrofo (') ocupa o lugar das letras que sumiram (woul).
  No Módulo 16 você vai pedir: {{I'd like a coke and French fries, please.|Eu gostaria de uma Coca-Cola e batata frita, por favor.}}
  Como frase pronta: **I'd like** + a coisa + **please**.
ex: I'd like a coke and French fries, please. | Eu gostaria de uma coca e batatas fritas, por favor.
ex: Please, I'd like a big soda. | Por favor, eu gostaria de um refrigerante grande.
ex: We'd like a table for two. | Nós gostaríamos de uma mesa para dois.
erro: I'd likes a coke. | I'd like a coke. | Eu gostaria de uma Coca-Cola. | O **'d** é **would**, e depois dele o verbo fica puro: sem -s.
erro: Id like a coke. | I'd like a coke. | Eu gostaria de uma Coca-Cola. | O apóstrofo (') é obrigatório: **I'd**.
quiz: I'd like quer dizer: | I would like | I would like; I did like; I do like
quiz: Pedindo uma coca: I'd ___ a coke, please. | like | like; likes; liking
